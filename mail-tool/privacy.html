Little Tide Mail Tool – Privacy Policy

Last updated: October 25, 2026

Who we are

Little Tide Mail Tool is a personal command-line tool run by the developer of Little Tide Games (contact: woosuk547@gmail.com). It is used only by its developer on the developer's own computer to read the developer's own mailbox. It is not offered to the public.

What Google data it accesses

  • Gmail messages and labels, read-only (gmail.readonly).
  • Your Google account email address and basic profile (to show which account is signed in).

For the personal mailbox the tool never sends, deletes or changes email.

The same tool is also signed in to the developer's own work account (a Google Workspace account of the developer's organization), where it may read and edit that account's own Gmail drafts and settings, Calendar, Drive, Docs, Sheets and Slides at the developer's request. It is never signed in to anyone else's account.

Why

To search and read messages in the signed-in user's own mailbox (for example, replies from app store and game portal support) at the user's request.

How data is stored and shared

  • Sign-in credentials are stored encrypted on the user's own computer. Messages are read on demand and are not stored on any server.
  • No Google user data is sold, shared or transferred to any third party, and it is never used for advertising.

Limited Use

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can remove the tool's access at any time at myaccount.google.com/permissions. Deleting the tool's configuration folder on your computer removes the stored credentials.
